## 🔄 8.2 Query 交互模块 (QIM)

### 作用
在帧间传递和更新跟踪 Query

### 主要步骤
```
1. 选择活跃的跟踪
2. 更新嵌入
3. 为下一帧准备
```

## 🏃 8.3 跟踪器工作流程

```
每帧：
1. 获取检测框
2. 模型预测
3. 过滤低分
4. 分配 ID
5. 更新历史
```
