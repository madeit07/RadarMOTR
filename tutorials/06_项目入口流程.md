# 阶段 6：项目入口流程

## 🎯 学习目标
- 理解训练主流程
- 理解评估主流程
- 掌握入口文件

## 📂 6.1 入口文件

| 文件 | 作用 |
|------|------|
| [main.py](../main.py) | 训练入口（Sacred实验 |
| [eval.py](../eval.py) | 评估入口 |
| [engine.py](../engine.py) | 训练和评估的引擎 |

## 🏋️ 6.2 训练流程 (main.py)

```
1. 初始化分布式环境
2. 构建模型
3. 构建数据集和加载器
4. 构建优化器
5. 训练循环
   - 前向传播
   - 计算损失
   - 反向传播
   - 更新参数
6. 保存检查点
```

### 关键函数
- `train(args, _run, _log) - 主训练函数
- `train_one_epoch() - 单轮训练

## 🏃 6.3 评估流程 (eval.py)

```
1. 加载模型权重
2. 遍历每个序列
   - 每帧跟踪
3. 保存结果
4. 运行评估指标
```
